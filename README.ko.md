# 동네축구 스쿼드 메이커

*[English README](README.md)*

선수 11명 이상의 능력치와 대략적인 역할(공격·미드필더·수비·골키퍼)만 입력하면,
각 선수에게 가장 잘 맞는 **역할(archetype)** 을 부여하고 스쿼드 전체의 부적합도가 최소가 되는
**포메이션과 전술**을 제안합니다. 할당 문제(assignment problem)를 헝가리안 알고리즘으로 풀어 계산합니다.

**▶ 데모:** https://jac2125.github.io/assets/html/squad-maker.html

## 작동 원리

1. **역할 정의** — 25개 archetype(타겟맨, 포처, 딥라잉 플레이메이커, 인버티드 윙어 등)마다
   핵심 능력치(가중치 3, 이상치 86)와 보조 능력치(가중치 2, 이상치 74)를 정의합니다.
2. **비용 함수** — 선수 *p* 를 역할 *r* 로 기용했을 때의 부적합도:

   ```
   cost(p, r) = 10 · sqrt( Σ wᵢ · max(0, idealᵢ − aᵢ)² / Σ wᵢ )  −  (Σ wᵢaᵢ / Σ wᵢ)
   ```

   부족분에만 벌점을 주고 이상치를 초과하는 부분은 벌점이 없습니다("이 역할을 수행할 수 있는가"를 측정).
   뒤의 항은 능력치가 더 좋은 선수가 선발되도록 유도하는 보너스입니다.
3. **최적 배정** — 포메이션마다 선수 × 슬롯 비용 행렬을 만들고(슬롯 비용 = 그 자리에 허용된 역할 중
   최소 비용), **헝가리안 알고리즘** O(n³) 으로 총비용을 최소화하는 배정을 계산합니다.
   로스터가 11명을 넘으면 비용 0인 더미 슬롯을 채워, 베스트 11 선발까지
   하나의 rectangular assignment 문제로 동시에 해결합니다.
4. **포메이션 비교** — 7개 포메이션(4-3-3, 4-2-3-1, 4-4-2, 3-5-2, 4-1-4-1, 3-4-3, 다이아몬드)을
   총비용으로 순위화합니다.
5. **전술 도출** — 배정된 역할 조합과 팀 능력치 분포(전방 스피드, 활동량, 수비 라인 속도 등)로부터
   빌드업 방식·공격 루트·수비 방식을 규칙 기반으로 제안합니다.

## 검증

- 헝가리안 구현을 2–7 크기 랜덤 행렬 300개에서 브루트포스 완전탐색과 대조 — 전부 일치
- 골키퍼 제약(GK 슬롯에는 GK만) 전 포메이션 확인
- 샘플 스쿼드 e2e 테스트에서 타겟맨·포처·볼플레잉 센터백 등 직관에 부합하는 배정 확인
